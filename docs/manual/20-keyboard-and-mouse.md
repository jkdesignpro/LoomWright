# Keyboard and mouse

This chapter lists every shortcut in LoomWright. **Help › Keyboard and mouse** shows the most used ones inside the app.

On a Mac, use <kbd>Cmd</kbd> wherever this manual says <kbd>Ctrl</kbd>; both work.

Single-letter shortcuts such as <kbd>R</kbd> and <kbd>T</kbd> do nothing while you are typing in a box; click an empty part of the sheet first.

## Files and windows

| Keys | What they do |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save as |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a project |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print or save PDF (all sheets) |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Search commands, sheets, parts and wires |
| <kbd>F1</kbd> | Open this manual |

## Editing

| Keys | What they do |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected parts and the wires between them |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cut |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select everything on the sheet |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selection |
| <kbd>R</kbd> | Rotate the selection a quarter turn clockwise |
| <kbd>Shift</kbd>+<kbd>R</kbd> | Rotate the other way |
| <kbd>F</kbd> | Flip the selection |
| Arrow keys | Move the selection 10 units |
| <kbd>Shift</kbd>+arrow keys | Move the selection 50 units |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Find and replace |
| <kbd>Esc</kbd> | Stop drawing a wire; otherwise clear the trace; otherwise clear the selection |

## Circuits

| Keys | What they do |
| --- | --- |
| <kbd>T</kbd> | Trace the selected wire's circuit |
| <kbd>Esc</kbd> | Clear the trace, or stop the live test |

## Moving around

| Keys | What they do |
| --- | --- |
| <kbd>+</kbd> or <kbd>=</kbd> | Zoom in |
| <kbd>-</kbd> | Zoom out |
| <kbd>0</kbd> | Fit the sheet to the window |
| <kbd>PgDn</kbd> | Next sheet |
| <kbd>PgUp</kbd> | Previous sheet |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Next and previous sheet (in the desktop app; a browser keeps these keys for its own tabs) |
| <kbd>Space</kbd> + drag | Pan |

Zoom, pan and the sheet keys also work during the live test.

## Mouse on the sheet

| Action | What it does |
| --- | --- |
| Click a pin, then another pin | Draw a wire |
| Click empty space while drawing a wire | Add a bend point |
| Click the starting pin again while drawing | Stop drawing the wire |
| Press on a pin and drag | Move the part |
| Click a part or wire | Select it |
| <kbd>Shift</kbd>+click | Add to or remove from the selection |
| Drag across empty space | Select the parts inside the box, and the wires between them |
| <kbd>Shift</kbd>+drag across empty space | Add to the selection |
| Drag a part | Move the selection |
| Double-click a part | Go to its first field in Properties |
| Double-click a wire | Add a bend point there |
| Drag a bend point | Move it |
| Double-click a bend point | Remove it |
| Drag the square handle on a selected wire | Move the middle run of the wire |
| Drag a wire label | Move the label; a leader line points back to the wire |
| Double-click a moved wire label | Put it back |
| <kbd>Alt</kbd>+click a wire or pin | Trace the circuit across every sheet |
| Click a cross-reference such as `→ 2/B4` | Go to the other end |
| Scroll | Pan up and down (sideways too, on a trackpad) |
| <kbd>Shift</kbd>+scroll | Pan sideways |
| <kbd>Ctrl</kbd>+scroll, or pinch on a trackpad | Zoom around the pointer |
| Drag with the middle button | Pan |
| Click a part during the live test | Move it to its next position |

## Parts pane

| Action | What it does |
| --- | --- |
| Drag a part or block onto the sheet | Place it there |
| Click a part or block | Place it in the middle of the view |

## Search (Ctrl+K)

| Keys | What they do |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the list |
| <kbd>Enter</kbd> | Choose |
| <kbd>Esc</kbd> | Close |

## Component builder

| Keys | What they do |
| --- | --- |
| <kbd>V</kbd> | Select and move |
| <kbd>L</kbd> | Line |
| <kbd>B</kbd> | Rectangle |
| <kbd>C</kbd> | Circle |
| <kbd>T</kbd> | Text |
| <kbd>P</kbd> | Pin |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selected shape or pin |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Esc</kbd> | Back to Select and move |

## Formboard and vehicle views

| Keys or action | What it does |
| --- | --- |
| <kbd>Esc</kbd> | Cancel joining or placing; otherwise close the view |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo, redo |
| <kbd>Delete</kbd> | Delete the selected branch or point (formboard) |
| <kbd>0</kbd> | Fit to the window |
| Drag empty space, or scroll | Pan |
| <kbd>Ctrl</kbd>+scroll | Zoom |

## This manual

| Keys | What they do |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>F</kbd>, <kbd>Ctrl</kbd>+<kbd>K</kbd> or <kbd>/</kbd> | Search the manual |

| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the contents or the results |
| <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Alt</kbd>+<kbd>→</kbd> | Back and forward |
